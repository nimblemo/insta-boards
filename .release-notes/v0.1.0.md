## v0.1.0 — Initial release

First public release of **`insta-boards`**, a CLI for backing up Instagram
Saved Collections into a local filesystem.

### Highlights

- **Single CLI, four subcommands** — `sync`, `list boards`, `list items`, `download` — replacing the previous four entry points.
- **State-aware incremental sync** — re-runs only pick up new items; safe to interrupt and resume (state is persisted after every item).
- **Human-like throttling** with `--no-humanize` opt-out for CI / tests.
- **Cursor-based pagination** with `--max-id` / `--output-cursor` for resumable walks of any collection.
- **GitHub Actions CI** on Python 3.11–3.13 + automated PyPI release via Trusted Publishing (OIDC, no API tokens).
- **MIT licensed.**

### Installation

```bash
uv tool install insta-boards
insta-boards --help
```

### Commands

| Command | Purpose |
| --- | --- |
| `insta-boards sync` | Full sync of all collections (state-aware, resumable). |
| `insta-boards list boards` | JSONL of every collection on the account. |
| `insta-boards list items --collection <id>` | JSONL of items in a single collection. |
| `insta-boards download --collection <id>` | Download a single collection into `data/raw/<slug>/`. |
